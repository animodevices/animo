# TYAFF site

Статический лендинг TYAFF (прежнее имя ANIMO). Русская версия в корне, английская в `/en/`.
Публикуется через GitHub Pages из ветки `main`: https://tyaff.com/ (домен в файле `CNAME`, записи DNS в Cloudflare, режим DNS only). Старый адрес animodevices.github.io/animo/ перенаправляет на него.

Исходник текущей версии лежит локально в `preview/site-v16` (английская главная в корне, русская в `/ru/`, армянская в `/hy/`; ролик шапки — черновик Seedance, улучшенный до 1440p, с нашими экранами (`media/hero-v16-hq-*`, на телефоне квадратная версия), сборка в `preview/hero-v16`; 3D-модели — в `preview/site-v14/_build`), новые файлы в `preview/` в git не попадают.

Прошлые версии доступны по адресам `/v14/`, `/v13/`, `/v11/`, `/v10/`, `/old/`, `/warm/`, `/minimal/`, `/sunset/`, все с noindex. Файлы `js/collar.js`, `media/collar.glb`, `media/collar-poster.webp`, `img/module.webp`, `img/og-v10.jpg` и ролики `media/hero-*.mp4` без `v16` и `js/collar-v13.js` нужны этим архивам, удалять их нельзя.
